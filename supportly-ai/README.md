# Supportly AI

Supportly AI is a multi-tenant AI-powered customer support SaaS platform.

Businesses will be able to:

- Train AI support agents on company knowledge
- Upload documents and crawl websites
- Ask questions using RAG
- Embed an AI support widget on websites
- Manage conversations in a shared support inbox
- Escalate conversations from AI to humans
- View customer support analytics
- Manage teams, permissions, usage and billing
